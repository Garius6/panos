# База данных (SQLite)

> Требует `импорт бд` и реальную файловую систему — **недоступно** в
> браузерной песочнице (см. [«Модули» → ограничение в
> браузере](./modules.md#ограничение-в-браузере)).
> Примеры не запускаются на странице, запускайте локально: `./panos файл.pns`.

## `бд`: подключение и запросы

```panos-cli
импорт бд

функ старт() -> Строка
    пер соед = бд.открыть("заметки.db").ожидать("не удалось открыть")
    соед.выполнить("CREATE TABLE IF NOT EXISTS заметка (id INTEGER, текст TEXT)", массив()).ожидать("create")
    соед.выполнить("INSERT INTO заметка VALUES (?, ?)", массив("1", "привет")).ожидать("insert")

    пер строки = соед.запрос("SELECT id, текст FROM заметка", массив()).ожидать("query")
    соед.закрыть()

    строки.получить(0, соответствие()).получить("текст", "(пусто)")
конец
```

- `бд.открыть(путь) -> Результат(Соединение_БД, Ошибка)` — открывает
  файл SQLite, создаёт его, если не было (тот же контракт, что
  `фс.открыть`)
- `Соединение_БД.выполнить(sql, параметры: Массив(Строка)) -> Результат(Число, Ошибка)` —
  INSERT/UPDATE/DELETE/CREATE и подобное. Число — количество
  затронутых строк
- `Соединение_БД.запрос(sql, параметры: Массив(Строка)) -> Результат(Массив(Соответствие(Строка, Строка)), Ошибка)` —
  SELECT, вся выборка сразу (см. [«Что не поддержано»](#что-не-поддержано)
  про большие результаты)
- `Соединение_БД.закрыть() -> Пусто`

`.выполнить`/`.запрос` выполняются в фоновом воркер-пуле (тот же
неблокирующий механизм, что у файловых дескрипторов и HTTP-сервера) —
дисковый I/O не блокирует остальные процессы panos.

## Параметры — только через `?`

`параметры` биндятся позиционно на `?`-плейсхолдеры в SQL. Отдельного
способа подставить значения прямо в текст запроса **нет** — это
осознанное ограничение, не пробел: конкатенация непроверенных строк в
SQL-текст — SQL-инъекция, а не удобство.

```panos-cli
импорт бд

функ старт() -> Строка
    пер соед = бд.открыть("пользователи.db").ожидать("не удалось открыть")
    соед.выполнить("CREATE TABLE IF NOT EXISTS ю (имя TEXT)", массив()).ожидать("create")

    пер имя_от_пользователя = "Робert'); DROP TABLE ю;--"
    соед.выполнить("INSERT INTO ю VALUES (?)", массив(имя_от_пользователя)).ожидать("insert")
    соед.закрыть()
    "безопасно вставлено как обычный текст, не как SQL"
конец
```

Без параметров — пустой массив: `соед.запрос("SELECT 1", массив())`.

## Значения колонок — всегда `Строка`

`.запрос()` возвращает каждую строку результата как
`Соответствие(Строка, Строка)`, ключ — имя колонки. SQLite сама
конвертирует любой тип (`INTEGER`/`REAL`/`TEXT`) в текст
(`sqlite3_column_text`) — обратно в число переводите сами, если нужно:

```panos-cli
импорт бд
импорт строки

функ старт() -> Число
    пер соед = бд.открыть("счётчик.db").ожидать("не удалось открыть")
    соед.выполнить("CREATE TABLE IF NOT EXISTS с (значение INTEGER)", массив()).ожидать("create")
    соед.выполнить("INSERT INTO с VALUES (?)", массив("42")).ожидать("insert")

    пер выборка = соед.запрос("SELECT значение FROM с", массив()).ожидать("query")
    соед.закрыть()

    пер текст = выборка.получить(0, соответствие()).получить("значение", "0")
    строки.в_число(текст).получить(0)
конец
```

### NULL

Колонка со значением `NULL` **отсутствует** в результирующей
`Соответствие` целиком — не пустая строка `""`, которая была бы
неотличима от настоящей пустой строки в базе. Проверяйте через
`.есть("колонка")`, читайте через `.получить("колонка", запасное)`:

```panos-cli
импорт бд

функ старт() -> Строка
    пер соед = бд.открыть("контакты.db").ожидать("не удалось открыть")
    соед.выполнить("CREATE TABLE IF NOT EXISTS к (имя TEXT, телефон TEXT)", массив()).ожидать("create")
    соед.выполнить("INSERT INTO к VALUES (?, NULL)", массив("Аня")).ожидать("insert")

    пер строки = соед.запрос("SELECT имя, телефон FROM к", массив()).ожидать("query")
    соед.закрыть()

    пер контакт = строки.получить(0, соответствие())
    если контакт.есть("телефон") тогда
        контакт.получить("телефон", "?")
    иначе
        "телефон не указан"
    конец
конец
```

## Что не поддержано

- **BLOB-колонки.** Если хотя бы одна колонка в результате `SELECT` —
  `BLOB`, весь вызов `.запрос()` вернёт
  `Результат.Неудача(Ошибка("бд", "BLOB-колонки не поддержаны в этой
  версии"))`. Молчаливая text-конвертация бинарных байт была бы потерей
  данных, а не удобством — явная ошибка честнее.
- **Типизированные значения.** Нет `Целое`/`Число`-варианта результата —
  только `Строка` (см. выше). Если нужно часто конвертировать —
  `строки.в_число(...)` на конкретных полях, где это важно.
- **Потоковая выборка.** `.запрос()` вычитывает всю выборку целиком за
  один проход воркер-потока — для очень больших результатов это
  разовая цена по памяти и времени, курсора/пагинации на уровне API
  нет.

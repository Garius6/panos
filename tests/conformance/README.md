# Conformance corpus

Этот каталог содержит наблюдаемые сценарии совместимости для Odin-эталона и
Zig-реализации Panos. До заполнения самого corpus `manifest.json` намеренно
пуст: его parser/validator уже входит в `zig build test`, но отсутствующие
языковые возможности не объявляются работающими раньше времени.

Каждый будущий case следует контракту
`specs/010-zig-migration/contracts/conformance.md`: устойчивый `id`, tier,
target profile, вход и нормализованный outcome. Сценарии с сетью, часами или
внешними процессами добавляются только с контролируемой подменой окружения.
